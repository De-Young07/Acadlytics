# Acadlytics — Future Data Requirements

## 1. Lecturer Dataset
Required fields:
- lecturer_id  
- course_code  
- session  
- assigned_students  

---

## 2. Graduation Dataset
Required fields:
- student_id  
- graduation_year  
- final_gpa  
- degree_class  

---

## 3. Alumni Dataset
Required fields:
- student_id  
- employment_sector  
- job_role  
- location  

---

## 4. Purpose

These datasets will enable:
- Lecturer performance evaluation  
- Graduation analytics  
- Alumni outcome tracking
