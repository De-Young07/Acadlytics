# Acadlytics — Project Definition

## 1. Overview
Acadlytics is a data-driven academic analytics platform designed to support students, lecturers, and department administrators in making informed decisions based on statistical evidence.

---

## 2. Problem Statement
The department currently lacks a unified system for monitoring academic performance. Decisions regarding curriculum, student support, and teaching effectiveness are often based on anecdotal observations rather than structured data analysis.

---

## 3. Objectives

The system aims to:

- Track student academic performance over time
- Identify at-risk students and courses early
- Evaluate course and lecturer performance
- Support administrative decision-making using data
- Provide transparent and interpretable insights

---

## 4. Stakeholders

### Students
- Monitor personal academic progress
- Identify weak areas
- Receive early warnings

### Lecturers
- Track class performance
- Identify struggling students
- Evaluate teaching outcomes

### Department Administrators
- Compare course performance
- Evaluate lecturer effectiveness
- Support resource and curriculum decisions

---

## 5. Key Questions

### Students
- How is my GPA evolving over time?
- Which courses are impacting my performance?
- Am I at academic risk?

### Lecturers
- What is the pass rate for my course?
- Are there early indicators of student difficulty?
- Which students require intervention?

### Administrators
- Which courses consistently underperform?
- How does lecturer assignment affect outcomes?
- Which courses create progression bottlenecks?

---

## 6. Scope (MVP)

### Included
- Student performance tracking
- Course-level analytics
- Basic lecturer performance insights
- Early risk detection indicators

### Excluded
- Full Learning Management System (LMS)
- Automated grading systems
- Chat-based assistants
- Alumni analytics (Phase 2+)

---

## 7. Success Criteria

The system will be considered successful if:

- Key stakeholder questions can be answered using data
- Metrics are consistently defined and applied
- Insights are interpretable and actionable
- Dashboards reflect real academic patterns
